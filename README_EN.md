# Fraud Analysis

Personal research on fraud schemes and social engineering.

## About

This repository contains anonymized case studies of fraud schemes
I encounter in practice. The goal is to analyze mechanics, psychology,
and technical traces of fraud.

All data is anonymized. Schemes are described for educational purposes.
